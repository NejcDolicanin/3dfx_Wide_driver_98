MDK

- Game version required. Retail + 3dfx patch + nocd patch.
  Because nocd patch is bit harder to find, I have included it in this folder.
- Set the Glide Resolution override in 3dfx Tools, ex 1920x1080
- Optional wideDriver.ini that you can copy next to the games exe.
  backdrop=2 - blackbars and the side for some sections (intro/outro gameplay).
  backdrop=1 - stretch the image for some sections.
