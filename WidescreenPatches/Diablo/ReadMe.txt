Diablo

- Game version required. Diablo retail + patch 1.09.
- Patch is built from Devilution port, add .exe in games root folder
- Add a [Video] section to diablo.ini and set Width and Height

Example:
[Video]
;Diablo_wide.exe only (Diablo.exe ignores this). 640x480 plays like the original;
;any width above 640 (a multiple of 4) with a height of 480 or more works if the
;display driver offers that mode at 256 colours, e.g. 1144x480, 1400x600, 1064x600.
;Width=1144
;Height=480
Width=1400
Height=600
