Aliens vs Predator Gold

- Game version required. Retail.
- Setting different resolutions is already supported since this is a Direct3d game, what this patch changes is ScreenProjection (fov) and hud scaling.
- Game crashing when changing in and out of campaigns (audio issue in the main menu) is also fixed. The rest of the game is untuched.
- Copy avp.exe to games root folder.


- OPTIONAL copy this folders avp_wide.ini to games folder, next to the avp.exe
  This will give you the option to further set HUD scaling. 100 is default, lower number is smaller hud, higher is bigger.
	
  More instructions in the .ini itself.
