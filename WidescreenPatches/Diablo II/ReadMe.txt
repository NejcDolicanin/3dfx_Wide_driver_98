Diablo II 

- Game version required. Diablo II retail + Lord of Destruction Expansion + LOD patch 1.13d.
- Set the Glide Resolution override in 3dfx Tools since the game is Sprite-based and made for 800x600,
  use the appropriate resolution 1064x600 for 16:9, 960x600 for 16:10, 1400x600 for 21:9
  
  It will work with other resolutions too, bu some thing might brake(edge rendering, enemy AI) and the scaling will make things small.
